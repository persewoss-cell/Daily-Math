# 매일 수학

학생들에게 매일 두 자리 수 &times; 두 자리 수 곱셈 문제 3개를 내주는 정적 웹사이트입니다. 별도 빌드 과정 없이 `index.html` 하나로 동작합니다.

## 기능

- 날짜가 같으면 학생들이 같은 문제를 보도록 날짜 기반 시드로 문제를 생성합니다. 기본 난이도는 문제 1은 하, 문제 2는 중, 문제 3은 상입니다.
- 문제별로 난이도(하 / 중 / 상)를 고르면 그 난이도에 맞는 숫자로 새 문제가 나옵니다. 숫자 0, 1, 2는 하 문제에만 나오고, 중 · 상 문제는 두 자리 모두 3~9 사이 숫자만 사용합니다.
  - 하: 10~29, 중: 33~59, 상: 63~99
- 문제별 "다른 문제" 버튼과 화면 상단 "전체 새 문제" 버튼으로 즉시 새 문제로 바꿀 수 있고, "되돌리기" 버튼으로 문제별 이전 상태로 한 단계씩 되돌아갈 수 있습니다.
- "정답 확인" 버튼을 누르면 그 문제의 정답이 화면에 팝업으로 바로 나타납니다.
- "전체 정답 이미지로 저장" 버튼을 누르면 세 문제의 정답이 나란히 담긴 PNG 이미지 하나가 다운로드됩니다.

## 로컬에서 보기

`index.html`을 브라우저로 열기만 하면 됩니다. 별도 서버나 빌드가 필요 없습니다.

## 배포 (GitHub Pages)

`.github/workflows/deploy-pages.yml`이 `main` 브랜치에 푸시될 때마다 자동으로 GitHub Pages에 배포하도록 되어 있습니다. 처음 한 번은 저장소 소유자가 수동으로 아래 설정을 해줘야 합니다.

1. 이 브랜치를 `main`에 머지합니다.
2. 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 설정합니다.
3. `main`에 푸시하면 Actions 탭에서 배포가 실행되고, 완료되면 `https://<owner>.github.io/<repo>/`에서 사이트를 볼 수 있습니다.
